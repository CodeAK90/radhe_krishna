# 🦚 Shri Radha Krishna - Python Neon Sketch ✨

A creative Python project that transforms a Radha Krishna neon artwork into a
**bottom-to-top animated sketch** using image processing.

The project detects the bright lines from the reference image and recreates
them step by step on a dark canvas, creating a simple neon drawing effect.

---

## 🛠️ Tech Stack & Libraries

- **Python 3.x**
- **OpenCV** – For image processing, line detection and animation.
- **NumPy** – For image and matrix operations.

---

## ✨ Features

- 🎨 Bottom-to-top sketch animation
- 🌈 Original neon colors
- 🌑 Dark background
- ✨ Subtle glow effect
- 📱 9:16 vertical format
- 🎬 MP4 video output
